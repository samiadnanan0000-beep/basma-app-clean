# خطة تنفيذ نظام التوثيق بالبريد الإلكتروني وكلمة المرور والبصمة

## 1. الأهداف الرئيسية
- **التسجيل لأول مرة (First-Time Registration):**
  - يدخل العميل: الاسم الرباعي، رقم الهاتف، والبريد الإلكتروني.
  - إرسال كود/رابط التفعيل الفعلي إلى البريد الإلكتروني عبر **Firebase Authentication Email Services**.
  - بعد التحقق من الرمز/البريد، يُطلب من المستخدم تعيين **كلمة مرور خاصة بحسابه** وخيار تفعيل **البصمة (Biometrics)**.
  - إسناد رتبة `CLIENT` للمستخدم الجديد تلقائياً، أو `ADMIN` في حال تطابق بيانات المشرف العام (سامي البكري: `samialbakri99@gmail.com`، `771051177`، `سامي عدنان حسن سيف البكري`).

- **تسجيل الدخول في المرات التالية (Subsequent Logins):**
  - واجهة تسجيل دخول مباشرة ومبسطة تطلب فقط: **البريد الإلكتروني** + **كلمة المرور** (دون المطالبة بالاسم والهاتف وكود التفعيل مجدداً).
  - إمكانية الدخول المباشر بنقرة واحدة عبر **بصمة الإصبع أو الوجه (Biometrics)** إن كانت مفعلة.

- **استعادة كلمة المرور المنسية (Forgot Password):**
  - زر "نسيت كلمة المرور" ينقل المستخدم لشاشة استعادة سريعة.
  - يدخل المستخدم بريده الإلكتروني المسجل.
  - يتم إرسال رسالة وكود إعادة تعيين كلمة المرور الفعلية إلى بريده الإلكتروني فوراً عبر Firebase.
  - إتاحة كتابة كلمة مرور جديدة وتأكيدها وتحديثها في Firebase Auth.

## 2. خطوات التعديل البرمجي في الملفات

### أ. ملف `AuthScreen.kt`:
1. تقسيم الشاشة إلى وضعين رئيسيين:
   - **وضع تسجيل الدخول (Sign-In Mode):** حقول (البريد الإلكتروني + كلمة المرور)، زر الدخول، زر الدخول بالبصمة، وزر "نسيت كلمة المرور"، بالإضافة إلى رابط "ليس لديك حساب؟ سجل الآن".
   - **وضع إنشاء حساب جديد (Registration Mode):**
     * الخطوة 1: إدخال (الاسم الرباعي، رقم الهاتف، البريد الإلكتروني) + زر "إرسال كود التفعيل إلى الإيميل".
     * الخطوة 2: إدخال كود التفعيل المستلم على الإيميل + تأكيد.
     * الخطوة 3: تعيين كلمة المرور وخيار تمكين البصمة، ثم إتمام التسجيل والدخول.
   - **حوار / وضع استعادة كلمة المرور (Forgot Password):** إدخال الإيميل وإرسال رابط/كود إعادة التعيين من Firebase Auth.

### ب. ملف `UserRepository.kt` و `MainViewModel.kt`:
1. إضافة دوال لإرسال رسائل التحقق عبر Firebase Authentication (`sendSignInLinkToEmail` / `sendPasswordResetEmail` / `verifyPasswordResetCode` / `createUserWithEmailAndPassword`).
2. حفظ بيانات الحساب وكلمة المرور المشفرة وربطها بالملف التعريفي في Firestore (`users/{uid}`).
3. تحديث فحص رتبة المشرف العام `ADMIN` وتثبيت رتبة `CLIENT` لبقية المسجلين.
4. تخزين حالة التفعيل والتسجيل محلياً في DataStore / Preferences لتظهر واجهة الدخول الاعتيادية بالبريد وكلمة المرور عند فتح التطبيق في المرات القادمة.

### ج. فحص وتأكيد التجميع:
- تشغيل `compile_applet` و `gradle :app:compileDebugKotlin` للتأكد من خلو المشروع تماماً من أي أخطاء تجميع أو تعارضات.
